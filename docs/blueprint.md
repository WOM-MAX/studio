# **App Name**: Idea Inbox

## Core Features:

- Note Capture: Quickly capture fleeting ideas and notes on the go using a simple text input field.
- Template Application: Apply pre-defined templates to notes for consistent formatting and structure for Obsidian.
- Template Storage: Store and manage note templates in a backend database for future use. Also provides an easy tab option where loaded templates can be selected from the writing system
- Authentication: Secure user accounts with email/password and passwordless login options, plus social login.
- PWA Support: Enable Progressive Web App (PWA) functionality for easy access from a mobile device's home screen.
- AI-Powered Tagging and Titling (Optional): Use Gemini AI tool to automatically analyze note content and suggest relevant tags and titles, providing an option to opt out for privacy.
- Google Keep Integration: Automatically apply the template and transfer new notes directly into an Google Keep vault, when the AI tagging and titling is applied, or the user can choose a name themselves and the template

## Style Guidelines:

- Primary color: A more golden yellow (#FFB300) to represent ideas and creativity.
- Background color: A deeper, darker blue (#1A237E) as a calming, sophisticated base.
- Accent color: Cyan (#00BCD4) for interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its modern, neutral appearance; highly readable and versatile.
- Simple, minimalist icons that are easy to understand at a glance.
- Clean, uncluttered layout with ample spacing.
- Subtle, non-intrusive animations for user feedback.
